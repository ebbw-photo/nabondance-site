# nabondance-chiro.fr

Site vitrine de Nathalie Abondance, chiropracteur à Paris 8e.
Site statique (HTML/CSS), publié par Netlify depuis la branche `main`, sans étape de build.

- `index.html` (accueil) et les pages françaises : `chiropraxie.html`, `pour-qui.html`, `mal-de-dos.html`, `nuque-maux-de-tete.html`, `grossesse.html`, `bebes-enfants.html`, `sportifs.html`, `stress-fatigue.html`, `parcours.html`, `consultation.html`, `questions.html`, `contact.html`
- `en.html` : version anglaise (une page)
- `style.css`, `images/`, `logo/`, `sitemap.xml`

Ne jamais publier l'adresse exacte du cabinet (domicile) : afficher « Paris 8e, Triangle d'Or ».

Publication : le dépôt doit rester public. L’offre gratuite de Netlify refuse de publier un dépôt privé quand les modifications ne viennent pas du compte du propriétaire (« unrecognized Git contributor »).
